Project Description
The Tip Calculator is an Android application developed using Kotlin and Jetpack Compose. It helps users calculate tips, total bills, and the amount each person should pay when sharing a bill.

Personalized Calculations

The calculations are based on the last four digits of my matric number.

* Matric Number: U24CP2014
* N: 2014
* Default Number of People (P): 8
* Rounding Increment (Δ): ₦0.15 / $0.15
* Default Tip Percentage (R): 19%

Application Features

1. Enter a bill amount.
2. Adjust the tip percentage using a slider.
3. Increase or decrease the number of people sharing the bill.
4. Calculate the tip amount.
5. Calculate the total bill.
6. Calculate the amount each person should pay.
7. Clear the entries and reset the calculator.

Technologies Used

* Kotlin
* Jetpack Compose
* Android Studio
* Visual Studio Code

How to Run the Application

1. Open the project in Android Studio.
2. Allow Gradle to sync.
3. Start an Android emulator or connect an Android device.
4. Click Run to launch the application.

Conclusion

This project demonstrates the use of Kotlin and Jetpack Compose to develop a simple, interactive Android Tip Calculator application.
